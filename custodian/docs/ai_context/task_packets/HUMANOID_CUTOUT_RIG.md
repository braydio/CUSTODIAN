# Humanoid Cutout Rig

- Status: `implementation / in-progress`
- Authority: `design/02_features/enemy_visuals/HUMANOID_CUTOUT_RIG_SYSTEM.md`
- Goal: Reuse generic rigid pivot motion across 96×96 humanoid enemy skins without moving simulation or replacing authored special strips.
- Runtime: `game/actors/enemies/visuals/humanoid_cutout_rig_2d.tscn`; `Enemy.visual_backend` remains authored frames by default.
- Asset contract: S/N/E static 480×384, 5×4 atlases with twenty absolute-positioned 96×96 part cells; optional W mirrors east only when the skin permits it.
- Source contract: one-frame 96×96 Aseprite documents under `content/_aseprite/sprites/enemies/<enemy_id>/source/rig/`; runtime atlases under `content/sprites/enemies/<enemy_id>/runtime/body/rig/`.
- Tools: `tools/aseprite/new_humanoid_rig_source.lua`, `tools/aseprite/export_humanoid_rig_atlas.lua`, and dry-run `tools/assets/scaffold_humanoid_rig_skin.py`.
- Validation: `godot --headless --path . --script res://tools/validation/humanoid_cutout_rig_smoke.gd`, then the existing grunt smoke and architecture ownership smoke.
- Constraints: no collision beneath pivots; no skeleton, mesh, weighting, or deformation; nearest filtering; generic animation never owns hit timing; no production art generated by scaffold unless the user supplies it.
- Fallback: Perspective-extreme/high-impact actions use authored replacement parts or a full-body authored strip. Falcon Punch, parry critical, paired execution, and bespoke directional specials remain authored-frame presentation.
- Dev review: `game/actors/enemies/dev/humanoid_cutout_rig_review.tscn` uses only unmistakable geometric placeholder art.
- Next slice: Author the first real S/N/E source set, export it, tune a per-enemy profile, and choose replacement-part versus full-body fallback for its first extreme attack. Do not migrate the grunt implicitly.

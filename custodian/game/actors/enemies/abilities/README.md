# Enemy Abilities

- Belongs here: reusable enemy ability modules such as phased dash, melee attack runners, parry receivers, and future special attacks.
- Does not belong here: base enemy health/movement contracts, procgen spawning, loot table data, HUD rendering.
- Current migration status: `grunt_falcon_punch.gd` owns the full Falcon phase machine, deterministic cadence, captured target, dynamic committed reach, target/ally/soft-world/hard-world collision classification, authored collision vulnerability/stand-up, reversal interruption, and telemetry; its typed tuning lives in `grunt_falcon_punch_config.gd` plus `configs/grunt_falcon_punch_default.tres`. `marine_dash.gd` now owns the complete tactical dash phase/clock, charge/prediction, contact/terminal, cadence and lateral-reset authority. `marine_dash_config.gd` preserves actor defaults; `configs/marine_dash_default.tres` preserves the tuned Marine scene. Target queries follow the host target as before; the one-shot predictive direction is ability-owned. `savage_pounce.gd` owns the complete pounce phase/cooldown/travel/contact/interruption authority and `SavagePounceConfig` owns the 13 typed tuning values via `configs/savage_pounce_default.tres`. `savage_chain.gd` owns the complete two-hit chain phase/timer/committed-facing/interruption lifecycle, with six chain-only values in `SavageChainConfig`; generic cadence, first damage/windup, and standard melee contact remain host services for NPA-4. No generic ability base is introduced.
- Current source of truth: `Enemy` supplies shared hit, engagement-token, presentation, camera/hitstop, separation, and observability services; extracted ability state lives in this directory.

Marine integration: `Enemy.get_marine_dash_ability()` exposes the typed ability, `request_marine_dash(direction, distance)` is the explicit authored/debug start seam, and `get_marine_dash_debug_state()` delegates a fresh read-only snapshot. Enemy ticks the ability at the existing fixed-step priority before strategic behavior. Shared movement, target qualification, hit, hitstop, camera, facing and animation requests remain actor services; the ability owns its warning-line lifecycle. Focused owners are `authored_vault_grunt_loot_marine` and `enemy_hit_spatial_telemetry`; ambush edits also select `sundered_keep_marine_ambush`. No generic ability base is introduced.

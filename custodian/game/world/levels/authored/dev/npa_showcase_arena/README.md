# NPA Showcase Arena

Generated through the canonical authored-level scaffold. Production geometry, markers and empty scenario sockets live in `npa_showcase_arena.tscn` and `npa_showcase_arena.gd`; the standalone wrapper owns the one Operator and gameplay systems. Add real actor scenarios only in their dedicated dependent packets.

The Broken Warrant actor is currently available through the development
console's `spawn_broken_warrant` command for focused playtests. Arena actor
sockets remain empty until a later integration slice owns their scenario
lifecycle; the actor uses provisional Grunt donor visuals pending its own
reviewed Asset V2 family and source art.

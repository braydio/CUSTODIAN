# Lords of Pain Test Gallery

This functional dev blockout covers seven available DEMO-pack semantic entries. Its deterministic source/runtime mapping and the three user-approved exclusions are recorded in `res://content/data/dev/lords_of_pain/gallery_manifest.json`.

- Arrow keys cycle the Warrior and Skeleton animation slots and all 16 authored directions.
- E toggles the local Gold Drop available/collected/reset sample.
- Highlight and Loot Indicator are fixed screen-space UI previews.
- The District Transfer Frame exit returns to the procgen origin through the normal authored-level route lifecycle.

The production scene never owns an Operator, camera, or PlayerController. Use `lords_of_pain_test_gallery_playtest.tscn` for the generated standalone wrapper.

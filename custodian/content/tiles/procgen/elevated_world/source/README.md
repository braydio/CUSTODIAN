# Elevated World Source References

These four 1536x1024 PNGs are concept montages used to guide the elevated-world presentation pass. They are intake/reference art only.

- They are not uniformly sliced atlases.
- Apparent transparency and backgrounds are not authoritative.
- Production art is rebuilt and stored as individual runtime files.
- Tile registration, shared-edge alignment, alpha, and seamlessness must be verified manually.
- Nothing under this `source/` directory may be referenced by a runtime TileSet or scene.

The named user-supplied montages were not present in the working copy when this pass was implemented. The checked-in references therefore preserve the closest existing repository concept art at the required source dimensions; they are not claimed to be normalized production sprites.

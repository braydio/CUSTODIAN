# Operator 2.5D Animation Viability Audit

Status: **migration evidence refreshed against the user-locked 2.5D authority**. This is a read-only audit. No Operator art, runtime behavior, catalog, manifest, SpriteFrames, sockets, frame timings, or Asset V2 content was changed.

## Executive result

The user has locked the target visual authority and the first canonical production animation. Pre-migration production-reachable art remains usable as legacy/runtime fallback, but it does not count toward canonical `operator_2_5d_128` coverage merely because it is live, directionally broad, or visually legible. The runtime-pixel matrices preserve that older art as migration evidence; they do not label it canonical or approve it as the new visual target.

The structural inventory contains **446 catalog identities**, **243 runtime-manifest identities**, **69 production-reachable legacy action families**, and **24 non-live/catalog-only action families excluded from the production migration backlog**. The first canonical target is `operator_2_5d_128 / unarmed / posture / idle_relaxed_01 / full_body`, with 8 directions x 15 frames x 128x128 cells. Its accepted source master is not yet present in this checkout's Operator source-work tree or published to the runtime manifest; the canonical-contract workstream owns that intake and registration.

**Migration counts:** 1 authored canonical family (not yet runtime-published); 68 production-reachable semantic families remain without a canonical 2.5D counterpart; the baseline backlog is 68 full-body 8-direction family atlases (544 direction-animation strips), before any additional modular, weapon, or FX layers are assigned. Existing legacy art is retained as fallback rather than repainted in place. No future projection/OMNI is yet approved as canonical completion.

## Runtime and composition findings

The generated catalog and live reachability ledger distinguish production-reachable rows from superseded, dormant, and catalog-only residue. The machine-readable inventory records direction, per-layer frame count and dimensions, FPS source, runtime path, projection policy, and composition for each legacy action family. All pre-migration runtime rows are marked `legacy_96` and `legacy_fallback_only` in `operator_2_5d_coverage.json`.

- Unarmed idle and walk have broad catalog directions but partial modular pairs; some diagonals in the legacy full-body route are projected horizontally.
- Unarmed run has full modular body pairs in all eight legacy directions, while selected full-body requests still project NE/NW.
- Legacy relaxed/ready posture and block families are primarily E/W. The canonical relaxed-idle source supplies a separate complete 8-direction target; it does not convert the old E/W runtime family in place.
- Unarmed attacks, melee, ranged and sidearm families retain their source-direction and projection evidence per family in the JSON inventory. These are migration inputs/fallback, not canonical completion.
- `Operator.set_fake_elevation()` remains presentation-only and preserves ground XY. This supports the fixed-isometric runtime architecture; it does not establish that legacy pixels meet the locked art direction.

The matrix images show current runtime strips at first/middle/last frames and visibly mark missing directions. They are bounded evidence of legacy coverage only. The Playable Knight remains a goalpost, not source art. The Lords of Pain archive was absent from both permitted local paths and was not fetched; the user-locked design sheet is the active visual authority, so that archive is not a blocker for this deterministic closeout.

# Alpine Plateau Starting Region Visual Lock

**Status:** locked  
**Date:** 2026-10-02  
**Scope:** first generated campaign starting region, `ALPINE_PLATEAU` frame  
**General frame authority:** `PROCGEN_REGION_FRAME_PROFILES.md`  
**Archive Resolve:** separate authority at `STREAMING_REVEAL_PRESENTATION_V1.md`  
**Visual source:** user-approved 2026-10-02 alpine/highland world reference image

## Authority

This document locks the **resolved appearance** of the first generated starting region.

It does not declare that every generated region is alpine, elevated, cliff-bounded or uses the same underlay.

The universal rule is instead:

> every generated region selects a region frame; the starting region selects `ALPINE_PLATEAU`.

Where older starting-region/procgen art notes conflict with this lock, this document wins for the Alpine Plateau starting region unless a location-specific authored-level document explicitly declares a deliberate exception.

## Core Read

The starting region is a **cold alpine frontier under organized ruined authority**:

- exposed rocky highland;
- conifer wilderness;
- patchy snow/frost;
- severe local elevation;
- engineered routes and retaining work;
- weathered civic/military hardstand;
- fortified Custodian logistics infrastructure embedded into terrain.

The dominant visual tension is:

**wild vertical terrain × disciplined hard infrastructure**

not generic wilderness × random sci-fi props.

## Local Biomes Stay Procedural

The `ALPINE_PLATEAU` frame is not a biome.

The existing local biome field remains generative:

- `rocky_upland`: dominant exposed/highland expression;
- `woodland`: cold conifer woodland, dark understory, exposed rock;
- `scrubland`: sparse wind-exposed scrub, stone and dead grass;
- `wetland`: bounded cold drainage/bog pockets.

Biome borders should interleave naturally inside the plateau. They should not look like four color-coded zones.

## Ground Palette

Prefer:

- charcoal/graphite stone;
- cold gray rock;
- desaturated brown/olive earth;
- muted moss/dead grass;
- off-white broken snow/frost;
- dirty melt edges;
- weathered stone/concrete/composite hardstand;
- faded ochre/amber service/route markings;
- sparse dark asphalt/bitumen notes.

Avoid saturated emerald vegetation, warm desert dominance, tropical color, clean white sci-fi paving, or blanket-white snow everywhere.

## Plateau And Exterior Edge

The region is a broad irregular upper plateau/highland shelf, not a tiny floating island.

The permanent edge stack is governed by `PROCGEN_REGION_FRAME_PROFILES.md`:

1. playable floor ends at an irregular exterior frontier;
2. world-positioned cliff lip/fascia descends from that frontier;
3. depth fog/cloud obscures the lower cliff;
4. a faint distant world below remains visible through/behind that atmosphere.

Internal ravines/pits are not automatically the exterior world edge.

Archive Resolve may move across still-unresolved playable plateau cells, but the cliff/fog/distant-world stack remains after the map is fully resolved.

## Hardened Infrastructure

Custodian occupation should read as engineered insertion into hostile terrain.

Preferred world-scale elements:

- weathered civic/military hardstand;
- reinforced service aprons;
- landing/transfer pads;
- retaining walls;
- barriers and guard rails;
- pylons and service masts;
- cargo stacks/field crates;
- relay/communications structures;
- fortified gates/checkpoints;
- maintenance yards;
- narrow engineered causeways.

Hardstand should feel like stone/composite/concrete slab systems adapted to severe terrain, not a pristine base-builder grid.

## Structures

Global structure grammar remains:
`custodian/design/02_art_direction/CUSTODIAN_STRUCTURE_DESIGN_CONTRACT.md`.

For Alpine Plateau emphasize:

- dark steel, blackened iron, cold stone-metal composite;
- substantial bases integrated with hardstand/retaining geometry;
- strategic vertical elements on major structures: pylons, mast clusters, guarded towers, signal spines;
- stacked logistics/service modules;
- readable exterior machinery;
- restrained insignia;
- frost, grime, snow dusting and repair scars;
- warm amber/brass work/navigation lights where mechanically useful;
- restrained teal/cyan only for established machine-state signaling.

Ordinary utility nodes should not become skyline towers. Strategic/authority structures may be taller and more monolithic while retaining function cues.

## Vehicles

Global vehicle authority remains:
`design/02_features/vehicles/VEHICLES.md`.

Alpine Plateau Custodian vehicles should read as:

- rugged expeditionary/logistics equipment;
- boxy and mechanically legible;
- reinforced and field-serviceable;
- charcoal/gunmetal/weathered olive;
- dirty canvas/tarp where useful;
- restrained brass/ochre markings;
- cargo/scanner/maintenance/transport fittings;
- snow, mud, grime and repair wear.

Preferred reads: utility truck, expedition carrier, field maintenance vehicle, survey/recon vehicle, cargo/relay support vehicle.

Avoid sleek civilian sports cars, glossy clean sci-fi shells, neon hover racers, scrap-heap apocalypse styling, or oversized weaponry as the default identity.

## World UI Shell

The normal field HUD remains in the Black Reliquary family, with this starting-region application:

- sparse graphite/charcoal presentation;
- warm ivory text;
- restrained brass/gold rules;
- thin technical brackets/ticks;
- geometric authority glyphs;
- compact uppercase metadata;
- generous negative space;
- minimal peripheral chrome.

The field HUD should read as an archival/survey instrument laid lightly over the world.

The reference's compass and minimap are **not** part of the current field-HUD lock. Existing minimap runtime capability remains valid for explicit surfaces; compass presentation remains deferred.

## Markers And Beacons

Use:

- thin amber/brass brackets;
- small corner ticks;
- geometric glyphs;
- narrow vertical locator stems;
- subtle registration rings;
- short uppercase tags;
- restrained acquisition pulse;
- tiny range/state metadata only when useful.

Markers should feel registered/attested/surveyed, not like generic RPG pins.

Avoid giant colored pins, bouncing exclamation marks, cartoon arrows, oversized floating text, or dense tactical reticles around every object.

## Iconography

Preferred iconography is:

- geometric;
- thin-line;
- symbolic;
- institutional;
- slightly ceremonial;
- mechanically plausible as signage/survey notation.

Favor diamonds, split circles, radial registration marks, clean structure/relay/gate glyphs, narrow chevrons and ticks.

Avoid fantasy runes, generic military-shooter stencil spam, emoji-like pictograms, glossy skeuomorphic buttons, and routine ornate gothic heraldry.

## Composition

At gameplay scale, visual hierarchy should usually read:

1. Operator / immediate threat;
2. traversable ground and cliff edge;
3. route / hardstand / structure frontage;
4. strategic structure or vehicle silhouette;
5. marker/beacon information;
6. small surface detail.

The strongest reference-composition rule is:

> large quiet dark/depth space around a sharply readable resolved landform and infrastructure.

Archive Resolve owns how still-unresolved playable terrain transitions into that resolved state. The region frame owns the permanent exterior depth around it.

## Anti-Drift

Reject direction that primarily reads as:

- lush fantasy forest;
- colorful biome sampler;
- generic post-apocalyptic wasteland;
- neon cyberpunk;
- pristine white sci-fi colony;
- gothic cathedral landscape;
- modern military simulator;
- flat RTS base;
- cozy alpine village;
- dieselpunk junkyard;
- UI-heavy tactical shooter.

The starting-region flavor is:

> **cold alpine plateau + ruined organized authority + hardened logistics infrastructure + severe elevation + permanent fogged world depth + restrained archival/brass field UI.**

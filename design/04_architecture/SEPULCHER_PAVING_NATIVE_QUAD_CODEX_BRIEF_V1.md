## Build operation

Implement a one-time, deterministic crop generator at:

`custodian/tools/art/sepulcher_paving_native_quad.py`

When that script is located there, its `REPO` path is `Path(__file__).resolve().parents[2]` (points to `custodian/`). Reference implementation:

```python
from pathlib import Path
from hashlib import sha256
from PIL import Image, ImageChops

REPO = Path(__file__).resolve().parents[2]
SRC = REPO / "asset_drop/source_work/hub/first_set/hub_first_set_sepulcher_gardens_floor_materials/paving_base_source.png"
OUT = REPO / "game/world/levels/authored/dev/sepulcher_modular_material_pilot/preview/generated"
EXPECTED = "62341f6850cd526b5b03187d9c9035318453c2b7cf2d6e213f19f1597af967bf"
assert SRC.is_file(), f"Staged master missing: {SRC}"
assert sha256(SRC.read_bytes()).hexdigest() == EXPECTED, "Wrong master bytes"
master = Image.open(SRC).convert("RGB")
assert master.size == (1254,1254)
rects = {
    "nw": ((128,128,640,640),(0,0)),
    "ne": ((640,128,1152,640),(512,0)),
    "sw": ((128,640,640,1152),(0,512)),
    "se": ((640,640,1152,1152),(512,512)),
}
OUT.mkdir(parents=True,exist_ok=True)
whole = Image.new("RGB",(1024,1024))
for key,(rect,offset) in rects.items():
    piece = master.crop(rect)
    assert piece.size == (512,512)
    piece.save(OUT / f"native_paving_{key}.png")
    whole.paste(piece,offset)
assert ImageChops.difference(whole,master.crop((128,128,1152,1152))).getbbox() is None
whole.save(OUT / "native_quad_reference_1024.png")
```

Only the four images are scene pieces; the 1024px reference is an equality/QA artifact. No PNG generated by this dev-only process is automatically an accepted Asset V2 `paving_base` or a published runtime asset. Keep the source untouched.
